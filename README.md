# LisM ESB v5.0.4 DIAG：续租与稳定性排查

同一套左手四向杆＋右手轨迹球，可以带去家里或单位使用：**A 站为原 Prospector 1.69 英寸，B 站为 XIAO147**。两台都在附近时保持当前连接，需要时用按键手动选站。

本次是 **v5.0.4 DIAG 排查版**，用于追踪两台接收器的左手断联、XIAO147 疑似重启、第三方指针图标和屏幕残留。软件修正与诊断已通过 47 项检查；**尚未证明实机断联、重启或残留已经解决**。

已修正／补充：

- 左手探测频率按最新有效路由命令判断，不再把空硬件 ACK 当作授权续租。维持原 1500ms 租约、失效冻结、重新准备／提交及松键屏障；没有放宽安全超时。失联时仍使用原有快速探测间隔，健康状态沿用慢探测。
- 复合键鼠按实际鼠标／触摸板 HID 能力选择指针图标；已连接且 ready 即可高亮，不以身份是否写入存储为门槛。输入报告解析、转发及品牌白名单没有修改。
- 两台接收器开启 Zephyr heap runtime stats，并保护界面统计调用，消除已确认的未初始化统计读取。它解释了旧日志的异常数值，但还不能证明是重启原因。
- 左手、右手加入每 5 秒一次的普通线程诊断；射频 ISR 中不加日志。启动标识改为 v5.0.4 DIAG，便于识别新固件。

屏幕残留仍在排查，本版不宣称已修复；WPM、屏幕驱动和刷新频率沿用 v5.0.3。保留 XIAO147 大字体、固定满亮度、不自动休眠，以及两台接收器的 USB／五槽 BLE 和双站功能。

后续再按排查进展更新右手及接收器，避免一次改动太多变量：

| 硬件 | 文件 |

| 左手，四向杆 | `LisM_ESBv504_DIAG_Left_4waystick.uf2` |

若刷后黑屏或不能输入，先单按一次接收器 Reset；UF2 刷后偶发启动异常仍未证明彻底修复。A／B 固件需对应硬件，不能交叉刷写。

## 使用与按键

Device 层仍用原来的进入方式（右手 Esc 位置按住，沿用 200ms）。下表的 F1／F2、H、分号和 N 等，指基础层对应的物理位置。

| 按键 | 作用 | 键图定义 |
| --- | --- | --- |
| Device＋右手 F1 | 优先选择 A：Prospector169 | `&kb_route KB_DONGLE_SEL(0)` |
| Device＋右手 F2 | 优先选择 B：XIAO147 | `&kb_route KB_DONGLE_SEL(1)` |
| Device＋H | 键盘通过右手直连电脑／手机／平板 | `&kb_route KB_BLE` |
| Device＋分号 | 返回 Dongle，优先上次成功使用的站点 | `&kb_route KB_DONGLE` |
| Device＋N／M／逗号／句号／斜线 | 键盘直连的 BLE 1～5 号位 | `&kb_route KB_BLE_SEL(0)` ～ `(4)` |
| 原 Screen Next 键 | 接收器下一页 | `&screen_next` |

右手 F1／F2 是 Device 层原本未定义的两个位置；保留其余已有键位、四向杆和轨迹球映射。Dongle 对电脑的 5 个 BLE 配置仍用原有 BT_SEL 快捷键，和上表键盘本机的 5 个位互不替代。

- **开机**：优先探测上次成功的站点，也会尝试另一站。都不可用时回退到键盘直连 BLE。
- **两个站点同时在附近**：不自动抢切。当前连接正常就保持；手动 F1／F2 可改选。指定站不可达时会尝试另一站，仍不可达则回退直连。
- **当前站断电或失联**：先安全停止旧输入，再重新寻找可用站；切换不是无缝漫游，需要松开按键和鼠标按钮。
- **按住按键／轨迹球按钮**：手动切换先等待真实释放。旧站已经排队的宏、组合键、保持点击必须完成释放确认，不能为了快速切站跳过它们。
- **已经回退或主动进入键盘直连 BLE**：后开机的 Dongle 不抢走输入，按 Device＋分号或 F1／F2 才回到 Dongle。
- **仅一只手暂时失联**：停止给它旧路径的许可，租约失效后允许右手单独完成切换；左手恢复后需重新准备与确认，不重放断线前的按下。

## 保留的功能

Dongle 模式仍是 **左手→当前 Dongle、右手→当前 Dongle 两条 ESB 直达路径**，轨迹球不会先绕另一只手。键盘直连模式是左手→右手 ESB，由右手 BLE 连接主机。每台接收器各自支持 USB、5 个主机 BLE 配置位、第三方蓝牙鼠标／触摸板及其开关。默认不扫描第三方设备；在设备页主动开启后才工作。

键盘直连时，可用的一台 Dongle 可以作为状态输出器，显示层、WPM、修饰键和电量，不接管键盘输入。两台同时出现时不会同时镜像：只选择当前已确认的显示接收器。

原屏保留 v4.7.2.1 的完整信号图标和较小 JOYSTICK 字体。XIAO147 保留 320×172 横屏和原有触摸，页面现在只有 STATUS／DEVICES，切页键及手势在这两页循环；没有 6 轴、飞鼠和自动旋转。设备页的摇杆导航、基础层 Enter 确认沿用原功能。

各台接收器的电脑 BLE 配对、第三方鼠标配对各自保存，不能把 A 的 5 个主机配置当作 B 的配置，也不会自动复制配对记录。

## XIAO147 搜索复测

在 DEVICES 页先将第三方蓝牙开关设为 ON，选择空位进入搜索；鼠标应先断开其他主机并进入配对模式。页面应显示大字 `Search: 30s` 并逐秒递减。有已保存设备时，可选择另一个空位添加；搜索结束后先 Back，再选择空位重试。默认不开启第三方蓝牙，不会仅因进入主页就主动添加设备。

若仍搜不到，保持 USB 连接以抓日志；新日志可区分触摸请求、后台接受、扫描启动返回值，以及是否收到广告／候选设备。无倒计时或只收到广告，并不能据此认定设备已被发现或可配对。此次没有增加扫描频率。

## 验证范围

四台诊断固件使用同一份源码指纹。验证覆盖实际 C 协调器、左右手无线帧与队列、站点／启动会话／epoch 核对、旧回包拒绝、松键与宏队列屏障、接收器单独重启、左手 COMMIT 后失联、直连 BLE 不被后来的 Dongle 抢走，以及显示／触摸回归。

47 项软件检查覆盖统计计数的缺陷负对照、复合指针图标、左手多个租约周期的空／重复 ACK、失效冻结和恢复，以及广播中扫描地址选择、触摸期间无关更新与身份替换、两页异步切换、固定亮度和不休眠。32 位 LVGL 内存模型覆盖配对弹窗及 40 次两页循环，稳态内存恢复；它不代表实机所有线程的运行时余量。

WPM 修正使用实际组件与 LVGL，在原屏 RGB565 字节交换开启、XIAO147 关闭交换的两种配置下，检查动态局部刷新与整屏重绘的像素一致性，覆盖峰值移动、归零后重新输入、状态镜像和信号图标覆盖区。

续租模型执行实际左手循环和报文接收，控制内容丢失时仍模拟硬件 ACK 成功；旧的硬件 ACK 判断在负对照中失败。模型不执行右手真实时隙调度、Nordic ACK FIFO 或物理窗口尾部截断；数据让行由周期快照检查，按键保序另外由原边沿回归覆盖。

软件通过不代表已经达到实机 1ms，也不代表已经完成两台接收器共处时的射频和触摸共存测试。请首先使用备用的一套键盘验证。
