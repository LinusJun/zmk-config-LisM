# XIAO147 v4.9 TEST

Current receiver core is based on the tested Prospector v4.7.2, with the v4.7.2.1 display alias fix. Fixed 320x172 JD9853A landscape and the existing AXS5106L automatic touch path are retained. No IMU/airmouse/automatic rotation or UART_RAW debug feature is enabled.

Use the byte-identical v4.7.2 left/right images. The old v4.8 halves use an incompatible routing protocol. This receiver has independent USB/BLE5 host output, two direct ESB hand links in Dongle mode, BLE5 keyboard-direct telemetry, a default-off third-party BLE switch, cached RSSI, source-owned touch buttons and route/UI/endpoint fences.

Hardware RF/touch/display performance remains to be tested. See the delivery readme and verification reports for exact scope.
