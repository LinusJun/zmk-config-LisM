LisM LEFT 4WAYSTICK + RIGHT TRACKBALL
====================================
Upstream GPIO reference:
https://github.com/4mplelab/zmk-config-LisM/blob/8e1fd16cc9fcae7dd7a92494dc0d48aa482e3e45/snippets/4waystick.overlay

Only the left module changes hardware role. The left PAW3222/SPI and split-input
listener are disabled; the right trackball wiring, processors, scroll-lock
layers, +8 dBm setting, and rate-limit/xyz modules are preserved.

Stock module directions (internal scan order):
Up=P0.10/NFC2, Right=D6, Down=D5, Left=D4.
All are active-low switches with internal pull-ups, as in the manufacturer's
firmware. There is no analog calibration and no assumed center-push switch.

Zero-based layer mappings, in human Up / Down / Left / Right order:
0 Base: vertical down / vertical up / horizontal right / horizontal left scroll
1 Game and 3 Mark: Left Shift / Left Control / Left Alt / Left GUI (Win/Command)
2 Nav: Up Arrow / Down Arrow / Left Arrow / Right Arrow
5 GameJoystick: W / S / A / D
4 Device and 7 reserved: transparent (inherit the currently active lower layer).
6 StickWASD: W / S / A / D (legacy compatibility; not the main entry).

The Base stick uses its own standard ZMK two-axis scroll behavior: press and
hold scrolls continuously, release stops. It uses a uniform 25 scroll units/s
without a ramp-up delay. Existing msc/encoder/trackball speeds are not changed.
Base wheel signs are reversed from the previous 4waystick test, following the
user's corrected table. Use the same macOS Natural scrolling setting as the
right trackball; actual page motion remains an on-device acceptance check.
Physical direction and preferred speed still need an on-device test. This is
not an analog trackball; the stick cannot sense how fast your hand moves.

Device layer, left second row first key (below Game): enter layer 5 GameJoystick.
The added left first row second shortcut also enters layer 5, not layer 6.
GameJoystick's original thumb return-to-Base key is retained.
Layer 6's old return-to-Base key remains for compatibility.

When first replacing the left trackball with 4waystick, use matching left,
right and dongle firmware: that change expanded the shared position map.
This mapping-only correction keeps the existing 46-position map and pins;
only the central dongle executes the corrected keymap, so peripherals already
on the 4waystick build do not need to be reflashed. Reset is not a required first
step. Existing BLE bonds can usually remain; rebuild pairing only if needed.
Retest press/release, layer changes while holding, modifier releases and BLE
disconnect while holding before relying on it in games.

The all-peripherals build retains JP19, Circle Pad and BOTH screen dongles.
The original-dongle branch stays based on codex/zmk-main-trackball-screen
34415d56632015e8844411a8b515759ec6eff797 (successful build 36221589002).
Do not mix the two dongle UF2 files; choose the one for your physical device.
